# 词性与提示修正

本次修正覆盖全部 440 个词汇条目：原有 89 个单词条目和 351 个词组条目。243 个句子／句架条目也标明表达类型。

- 单词在中文释义上方显示 `n. 名词`、`v. 动词`、`adj. 形容词` 等标记。
- 词组按实际结构区分动词短语、名词短语、介词短语、副词性短语、分句和关联结构。
- 兼类词按当前含义标注本条词性，答对后的详情另列其他常见词性，避免把某个词永久限定成一种词性。
- 单词都有中文语境提示。修正了原本只有“通用、最稳妥”而缺少“重要的”，或只有英文语法结构而缺少中文含义的条目。
- 词性同时出现在拼写练习、词库列表、词条详情和答对后的用法区。
- 英文答案仍默认隐藏，只在下划线位置显示用户输入，按 Enter 后判断。

## 维护

`data/word-senses.tsv` 保存本条词性、中文含义、语境和其他常见词性。`tools/enrich_catalog.py` 明确标注短语类型，遇到未覆盖词或结构会报错，要求检查。

`tools/import_material.py` 重新导入时会合并译文并恢复词性。`public/assets/grammar.json` 由同一份标注生成，前端将它合并到词库；这样旧的本地服务进程不重启也能读到修正。新增或修改标注后执行：

```text
python tools/enrich_catalog.py
```

词性按当前提示的具体义项确定。例如练习／实践这一条考名词；“实际的／实用的”一条考形容词。“影响”相关词按当前用法分别考动词或名词，不把所有兼类用法混在同一道提示里。

词典核对参考：[practice](https://dictionary.cambridge.org/dictionary/english/practice)、[practical](https://dictionary.cambridge.org/dictionary/english/practical)、[effect](https://dictionary.cambridge.org/dictionary/english/effect)、[progress](https://dictionary.cambridge.org/grammar/british-grammar/progress)。词条详情中也提供对应词典入口。

这次只增加提示与语法字段，保留原有卡片 ID、账号、学习记录和复习安排。使用本地版本时刷新网页即可；云端部署后更新代码并重建应用镜像。
